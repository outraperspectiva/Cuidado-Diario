## Contexto

A interface segue uma identidade visual definida em [STD-0001](../standards/STD-0001-IDENTIDADE-VISUAL.md), com paleta e tipografia próprias.

## Decisão

Adotar **Tailwind CSS** para estilização, com a paleta e as fontes da identidade visual configuradas como tokens.

## Consequências

- Estilos consistentes entre telas.
- Mudanças de paleta ou tipografia ficam concentradas na configuração.
