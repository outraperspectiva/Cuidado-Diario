| Termo | Definição |
| --- | --- |
| Adesão medicamentosa | Proporção de doses tomadas em relação às doses previstas. |
| Dose | Uma tomada prevista de um medicamento em um horário. |
| Status da dose | **Pendente** (ainda não registrada), **tomada** ou **pulada**. |
| Estoque | Quantidade de medicamento disponível; gera alerta quando baixa. |
| Turno | Período do dia usado para listar os medicamentos na tela Hoje. |
| Prescrição de fisioterapia | Exercício prescrito, com horários, séries, repetições e tempo de sustentação. |
| Sessão | Uma execução prevista de uma prescrição de fisioterapia (sessão n de total). |
| Série / Repetição | Número de conjuntos de um exercício / número de vezes em cada conjunto. |
| Tempo de sustentação | Segundos em que a posição do exercício é mantida. |
| EVA | Escala visual analógica de dor, de 0 (sem dor) a 10 (pior dor). |
| Registro de dor | Anotação de nível, localização, tipo e fatores desencadeantes em um momento. |
| Crise | Registro de dor marcado como crise (`isCrisis`). |
| SOS Crise | Ação de emergência disponível na tela Hoje. Comportamento a definir em [PRD-0004](../products/PRD-0004-DOR-E-SINTOMAS.md). |
| Modo visitante | Acesso imediato em modo demonstração, sem login. |
| Card Azul | Card de destaque da tela Hoje, com a data formatada. |
| LGPD | Lei Geral de Proteção de Dados (Lei 13.709/2018). |
